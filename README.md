# Конструктор КП · WE Media

Коммерческие предложения в стиле WE Media за пару кликов: вставьте свой
текст — получите готовую презентацию 16:9 и скачайте PDF. Работает целиком
в браузере, сервера нет, тексты никуда не отправляются. Один файл
`index.html`, внутри уже лежат шрифты Montserrat и Inter, логотип и иконки.

Сделан по логике [edubridge](https://github.com/ehroz1/edubridge): экран
выбора с живыми превью, редактор «слайды · превью · поля», черновики в
браузере, отмена, установка как приложение и работа офлайн. Главное отличие —
**текст → слайды**: у коллег свой текст всегда есть, поэтому вставка текста —
основной сценарий, а не дополнительный.

Стиль зашит строго по [docs/style-guide.md](docs/style-guide.md)
(«Executive Visibility by WE Media», светлая версия v4): 1920 × 1080, поля
96/120/80, Montserrat 800 и Inter, фирменный синий `#0044FF`, градиент VIVID
с зерном, растущие столбики, кольца, сетка квадратов, огромные обрезанные
цифры. Тёмных фонов, тёплых цветов, скруглений и межбуквенного расстояния нет.

## Как пользоваться

### 1. Текст → презентация

На первом экране:

- **Вставить из буфера** — одна кнопка; или ⌘V / Ctrl+V в поле;
- **Открыть файл** или просто перетащите в поле файл Word (.docx), .txt или .md.

Форматирование из Word и Google Docs понимается: заголовки становятся новыми
слайдами, списки — пунктами, таблицы — слайдом «Сравнение пакетов». Справа
сразу видно, какие получатся слайды. **Собрать презентацию** — и всё готово.

Раскладка каждого слайда подбирается сама — по смыслу заголовка («Проблема»,
«Зачем», «Что делаем», «Этапы», «Форматы», «Итог», «Пакеты», «Стоимость»,
«Контакты») и по форме текста: сколько пунктов, есть ли описания, цены,
таблица. Соседние слайды стараются не повторяться, синий слайд-итог — не чаще
раза на 4–6 слайдов, как в гайде.

**Текст не меняется.** Он только раскладывается по местам: «Аудит — изучаем
медиа» становится заголовком и текстом пункта, «Помесячно — 900 000 ₸» —
строкой стоимости. Кнопка **«Текст сверен»** сверху сравнивает слайды с
исходником и подсвечивает, если какие-то слова не попали на слайды.

Если хочется управлять разбивкой точно — простая разметка (кнопка «Как
размечать текст»):

```
# Что мы делаем          ← новый слайд
- Формируем позиционирование
- Готовим колонки и интервью

# Пакеты
## BASE                  ← каждый пакет — отдельный слайд
Для тех, кто начинает
- 2 колонки в месяц
Стоимость: 800 000 ₸ в месяц

| | BASE | PRO |         ← таблица → «Сравнение пакетов»
| Интервью | — | ✓ |
---                      ← новый слайд без заголовка
*слово*                  ← синий акцент в заголовке
```

### 2. Правка

- Слева — слайды: перетаскивайте, дублируйте, удаляйте. **+ Слайд** — любой из
  13 типов с живым превью.
- Справа — поля слайда. **Щёлкните по тексту на превью** — курсор встанет в
  нужное поле.
- **Раскладка** — превью этого же слайда во всех 13 вариантах. Один клик
  меняет вид, текст остаётся. Если раскладка что-то не показывает, справа
  будет предупреждение — текст сохранён и вернётся при смене раскладки.
- **Текст подстраивается сам**: если не влезает, кегль уменьшается (не меньше
  24 px — правило гайда). Если и так тесно — кнопка **«Разбить на 2 слайда»**.
  **Aa** под превью делает текст на слайде мельче, если хочется воздуха.
- В пустой слайд можно вставить кусок текста целиком — заголовок, абзац и
  пункты разложатся по полям. В пустой список — несколько строк сразу.
- Таблицу пакетов можно вставить из Excel или Google Таблиц в любую ячейку.

### 3. Оформление

Блок **Презентация** справа:

- **Надпись в шапке** («EXECUTIVE VISIBILITY») — набирается капсом сама. Это и
  номер слайда — единственное, что конструктор добавляет от себя.
- **Номера слайдов** — включить или выключить.
- **Логотип клиента** — встаёт на обложке и в контактах рядом с логотипом
  WE Media через тонкий разделитель; можно сделать монохромным.

Цвета, шрифты, отступы и графика зашиты в раскладки и не настраиваются —
так все КП выглядят одинаково дорого.

### 4. Экспорт

- **Скачать PDF** — откроется окно печати: выберите **«Сохранить как PDF»**,
  имя файла уже подставлено. Страницы 1920 × 1080, текст остаётся текстом
  (можно выделять и искать), файл лёгкий. Лучше всего в Chrome, Edge или
  Яндекс Браузере. ⌘P тоже печатает всю презентацию.
- В меню рядом: **PNG · ZIP** — все слайды картинками, **PNG** — текущий
  слайд, **HTML** — один файл, который открывается в любом браузере и
  листается стрелками (F — на весь экран).
- **▶** — показ на весь экран прямо из редактора (F5 — с начала,
  ⇧F5 — с текущего слайда).

### Горячие клавиши

⌘Z / ⌘⇧Z — отменить / повторить, ⌘P — PDF, F5 — показ, ⌘D — дублировать
слайд, PageUp / PageDown — соседний слайд, Esc — закрыть окно, ⌘Enter на
первом экране — собрать презентацию.

### Типы слайдов

| Слайд | Как выглядит |
|---|---|
| Обложка | логотип сверху, крупный заголовок и подзаголовок, растущие столбики |
| Тезис | одна крупная мысль; один короткий заголовок — разделитель раздела |
| Проблема / контекст | тезис и колонки с линией сверху, справа сетка квадратов |
| Польза: 3 колонки | заголовок и лид, колонки 01–03, кольца в углу |
| Что делаем | синяя панель с заголовком и тремя квадратами, справа нумерованный список |
| Этапы | карточки с огромной обрезанной цифрой, первая синяя |
| Список | заголовок слева, нумерованный список справа, кольца |
| Текст | заголовок, лид и абзацы, пункты списком |
| Итог | синий слайд с зерном, цифра на фоне, белая плашка-цепочка |
| Пакет | название синим, курсивный подзаголовок, «Всё из …, плюс:», уровень в шапке, цена |
| Сравнение пакетов | таблица, последний пакет синий, ✓ и «—» |
| Стоимость | полосы: базовая, «за год» синяя со скидкой, голубая, серая |
| Контакты | финальный слайд с кольцами |

### Черновики и офлайн

Черновики сохраняются в этом браузере автоматически (до 60 штук) — блок
**Мои КП** на первом экране. Другой браузер или компьютер их не видит:
финальный вариант храните в PDF.

На сайте браузер предложит **установить** конструктор как приложение — после
этого он открывается отдельной иконкой и работает без интернета.

## Как выложить для коллег (GitHub Pages)

1. В репозитории откройте **Settings → Pages**.
2. **Source: Deploy from a branch**, ветка **main**, папка **/ (root)** → **Save**.
3. В репозитории лежит `CNAME` с адресом `we-kp.picta.cc` — у домена должна
   быть CNAME-запись на `<логин>.github.io`.

`index.html`, `manifest.webmanifest` и `service-worker.js` всегда
собираются и выкладываются вместе — офлайн-режим работает, только если все
три лежат рядом.

## Для разработчика

### Сборка

Приложение, которое реально открывается, — сгенерированный `index.html`.
Править нужно `src/` и `brand/`, потом пересобрать:

```bash
pip3 install fonttools brotli   # урезает шрифты до латиницы и кириллицы с казахскими буквами
python3 build.py
python3 -m http.server 8000     # http://localhost:8000
```

Без fontTools сборка тоже пройдёт, просто шрифты встроятся целиком и файл
станет тяжелее.

### Структура

```
index.html               готовое приложение (генерируется)
manifest.webmanifest     манифест PWA (генерируется)
service-worker.js        офлайн-кеш (копируется из src/)
build.py                 сборка; генерирует и зерно grain.png
src/
  layouts.js             ВСЕ раскладки слайдов (KINDS), модель данных, примеры, структуры КП
  slides.css             стили слайдов 1920×1080 — по гайду
  importer.js            текст / HTML / .docx → разметка → слайды; сверка текста
  app.js                 интерфейс: старт, редактор, «уместить», отмена, показ, экспорт
  styles.css             оформление интерфейса (светлая и тёмная тема)
  index.template.html    каркас страницы
brand/
  fonts/                 Inter 400–700 (+ курсив 500, 700) и Montserrat 800 (SIL OFL)
  logo/                  логотип WE Media Group (берётся контур)
  ui/                    иконки интерфейса — Phosphor Bold (MIT)
  pwa-icon*.svg/png      иконка приложения
docs/style-guide.md      стиль презентаций КП — источник всех цифр
```

### Как добавить тип слайда

1. В `src/layouts.js` добавьте запись в `KINDS`: `name`, `group`, `about`,
   `fields` (какие поля общей модели показывает раскладка и как они
   подписаны) и `render(data, env)`, который возвращает HTML слайда.
   Блоки, которые могут переполниться, помечайте `data-fit` — по ним
   «уместить» подбирает кегль.
2. Стили — в `src/slides.css`, все кегли через `calc(Npx * var(--k))`, текст
   не меньше 24 px (`max(24px, …)`).
3. Пример текста — в `SAMPLE`, при желании — правило выбора в
   `src/importer.js` (`INTENTS` и `sectionSlides`).
4. `python3 build.py` — тип появится в «+ Слайд» и в «Раскладке» сам.
